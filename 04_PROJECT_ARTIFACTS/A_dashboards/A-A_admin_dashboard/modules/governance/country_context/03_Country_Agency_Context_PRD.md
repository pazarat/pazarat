# Country Agency Context PRD — سياق الوكيل التشغيلي

## الهوية

**الأب:** `CountryContext_PARENT_PRD.md`
**النوع:** Child PRD

الوكيل = حساب مستخدم موجود + قدرة الوكيل. لا يُنشئ حساباً جديداً.

---

## العلاقة مع User Management

| القسم | الدور |
|-------|-------|
| User Management | إدارة الحساب الأساسي |
| Country Agency | إدارة قدرة الوكيل وعقده |
| Agent Dashboard | واجهة الوكيل اليومية |

---

## الحالات (State Family: AgentStatus)

| الحالة | المعنى |
|--------|--------|
| `candidate` | طلب تعيين مُقدَّم |
| `pending_contract` | ينتظر إنشاء العقد |
| `active` | نشط وله عقد ساري |
| `suspended` | معلَّق مؤقتاً |
| `terminated` | العقد انتهى |
| `capability_revoked` | القدرة أُزيلت |

---

## العقد التشغيلي

العقد يحدد صلاحيات الوكيل (form):

| الحقل | الوصف |
|-------|-------|
| الحساب المرتبط | من User Management |
| الدولة التشغيلية | سياق الدولة |
| نوع العقد | كامل / جزئي / مؤقت |
| تاريخ البدء / الانتهاء | |

### الصلاحيات

| الصلاحية | نعم/لا |
|----------|--------|
| إدارة الشحن | |
| السحب المالي (مع حد أقصى) | |
| إدارة المخزون | |
| إدارة التصنيفات | |
| إدارة البائعين | |
| إدارة الطلبات | |
| إصدار فواتير | |
| التواصل مع العملاء | |

---

## حالات العقد (State Family: AgentContractStatus)

| الحالة | المعنى |
|--------|--------|
| `draft` | قيد الإنشاء |
| `pending_approval` | ينتظر موافقة |
| `active` | ساري |
| `expired` | انتهى التاريخ |
| `terminated_early` | أُلغي قبل موعده |
| `suspended` | معلَّق |

---

## ملاحظات

- الوكيل يبقى حساب مستخدم عادي في User Management
- تعطيل الدولة يُعطل عمليات الوكيل تلقائياً (ربط سياقي)
- قدرة الوكيل تُضاف/تُزال مثل أي قدرة
