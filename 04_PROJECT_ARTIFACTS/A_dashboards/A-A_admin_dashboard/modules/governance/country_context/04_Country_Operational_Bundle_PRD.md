# Country Operational Bundle PRD — الحزمة التشغيلية للدولة

## الهوية

**الأب:** `CountryContext_PARENT_PRD.md`
**النوع:** Child PRD

عرض تنسيقي لحالة كل قسم مرتبط بدولة. لا يملك أي منطق - فقط يعرض ويربط.

---

## ماذا يعرض

عند فتح الحزمة لدولة:

| القسم | الحالة | الإجراء |
|-------|-------|---------|
| الشروط والأحكام | افتراضي / مُضبط | رابط للقسم |
| إعدادات الضرائب | افتراضي / مُضبط | رابط للقسم |
| إعدادات الشحن | افتراضي / مُضبط | رابط للقسم |
| قالب التحقق | افتراضي / مُضبط | رابط للقسم |
| إعدادات الجمارك | افتراضي / مُضبط | رابط للقسم |
| العمولات | افتراضي / مُضبط | رابط للقسم |

---

## حالات القسم بالسياق

| الحالة | المعنى |
|--------|--------|
| `default` | لم يُضبط - يستخدم القيم العامة |
| `configured` | مُضبط لهذه الدولة |

---

## ملاحظة

**لا إعدادات هنا.** فقط عرض حالة + رابط للقسم المالك. التعديل يتم في القسم المالك.
