# Country Registry PRD — سجل الدول

## الهوية

**الأب:** `CountryContext_PARENT_PRD.md`
**النوع:** Child PRD
**bilt:** Child

سجل الدول يعرض الدول المُزروعة من الكود وحالاتها. لا ينشئ دويلات جديدة.

---

## البيانات المعروضة

| الحقل | قابل للتعديل؟ |
|-------|---------------|
| اسم الدولة | ثابت (من الكود) |
| رمز ISO | ثابت (من الكود) |
| النوع (أم/توسعة) | ثابت |
| الحالة التشغيلية | نعم |
| مرئي للتسجيل | نعم |
| مرئي كسوق | نعم |
| الشروط والأحكام | عرض حالة فقط |
| إعدادات الضرائب | عرض حالة فقط |
| إعدادات الشحن | عرض حالة فقط |
| قالب التحقق | عرض حالة فقط |

---

## الحالات (State Family: CountryContextStatus)

| الحالة | المعنى |
|--------|--------|
| `active` | نشطة بالكامل |
| `registration_only` | تسجيل فقط |
| `market_visible` | سوق فقط بدون شراء |
| `disabled` | معطلة بالكامل |
| `suspended` | مؤقتاً - الحسابات القديمة تعمل |

---

## الإجراءات

| الإجراء | الحدث |
|---------|-------|
| تفعيل | `country_activated` |
| تعطيل | `country_disabled` |
| تعليق مؤقت | `country_suspended` |
| إظهار السوق | `country_market_shown` |
| إخفاء السوق | `country_market_hidden` |
| فتح التسجيل | `country_registration_opened` |
| إغلاق التسجيل | `country_registration_closed` |

---

## الحماية

- لا حذف دولة مُعرّفة
- لا تعديل رمز الدولة
- لا تعطيل الدولة الأم (فقط تعليق جزئي)

---

## عرض حالة الأقسام

عند فتح تفاصيل دولة، يظهر ملخص:

| القسم | الحالة | الإجراء |
|-------|-------|---------|
| الشروط والأحكام | افتراضي / مُضبط | رابط |
| الضرائب | افتراضي / مُضبط | رابط |
| الشحن | افتراضي / مُضبط | رابط |
| قالب التحقق | افتراضي / مُضبط | رابط |
| الجمارك | افتراضي / مُضبط | رابط |
| العمولات | افتراضي / مُضبط | رابط |

**ملاحظة:** عرض حالة فقط - التعديل في القسم المالك.
