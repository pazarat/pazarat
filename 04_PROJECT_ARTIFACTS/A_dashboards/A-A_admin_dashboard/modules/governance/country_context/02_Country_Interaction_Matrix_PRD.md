# Country Interaction Matrix PRD — مصفوفة التفاعل بين الدول

## الهوية

**الأب:** `CountryContext_PARENT_PRD.md`
**النوع:** Child PRD

المصفوفة تقول **مسموح / ممنوع** فقط. لا تُغيّر منطق الأقسام.

---

## الأبعاد

| البعد | الوصف |
|-------|-------|
| Account Country | دولة حساب المشتري |
| Market/Store Country | دولة السوق أو المتجر |
| Delivery Country | دولة التوصيل |
| Operation Type | نوع العملية |

## أنواع العمليات

| النوع | الوصف |
|-------|-------|
| `browse` | تصفح |
| `purchase` | شراء |
| `ship` | شحن |
| `register` | تسجيل حساب |
| `sell` | بيع / فتح متجر |

## القرارات

| القرار | المعنى |
|--------|--------|
| `allowed` | مسموح - المنطق العادي يعمل |
| `blocked` | ممنوع - رسالة للمستخدم |
| `seller_responsible` | مسموح لكن الشحن مسؤولية البائع |
| `restricted` | مسموح بشروط |

## القواعد الافتراضية

1. **نفس الدولة** = مسموح دائماً
2. **دولة معطلة** = ممنوع
3. **التصفح** = مسموح لأي دولة نشطة كسوق
4. **الشحن عبر الحدود** = يُقرَّر حسب المصفوفة

## أمثلة

| المشتري | المتجر | التوصيل | العملية | القرار |
|---------|--------|---------|---------|--------|
| لبنان | سوريا | لبنان | تصفح | مسموح |
| لبنان | سوريا | لبنان | شراء | مسموح |
| مصر | سوريا | تونس | شراء | ممنوع |
| السعودية | الإمارات | السعودية | شحن | مسؤولية البائع |

## ملاحظة

المصفوفة **لا تُنشئ منطقاً جديداً**. تقول فقط "مسموح بين هاتين الدولتين؟". التنفيذ يبقى في القسم المالك.
