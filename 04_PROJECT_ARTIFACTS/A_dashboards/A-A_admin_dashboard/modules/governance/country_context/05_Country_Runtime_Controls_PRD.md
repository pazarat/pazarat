# Country Runtime Controls PRD — ضوابط تشغيل الدولة

## الهوية

**الأب:** `CountryContext_PARENT_PRD.md`
**النوع:** Child PRD

مفاتيح تفعيل/تعطيل الدولة. لا تُغيّر بيانات - فقط تتحكم بالتشغيل.

---

## المفاتيح

| المفتاح | الوصف | الإيقاف يعني |
|---------|-------|-------------|
| `is_active` | نشطة تشغيلاً | كل العمليات متوقفة |
| `allow_registration` | السماح بالتسجيل | لا تسجيل - القديم يعمل |
| `show_in_market_filter` | الظهور في فلتر السوق | لا تظهر في القائمة |
| `allow_purchasing` | السماح بالشراء | تصفح فقط |
| `allow_new_orders` | السماح بطلبات جديدة | القديم يُكمل فقط |

## الحماية

- لا حذف دولة بها حسابات نشطة
- التعطيل لا يؤثر على السجلات التاريخية
- إعادة التفعيل تعيد التشغيل حيث توقف

## ملاحظة

هذه المفاتيح **لا تُفعّل الأقسام تلقائياً**. تفعيل الدولة = 活化 السياق. كل قسم يبقى على حالته (افتراضي / مُضبط).
